# Notice about snapshots/

Everything under `snapshots/` (and the quoted lines in `site/diffs/`) is text
copied from public, logged-out web pages of the vendors listed in `pages.toml`.
That text belongs to its publishers. It is **not** covered by this repository's
Apache-2.0 or CC BY 4.0 licenses.

It is kept so that changes can be reviewed and reported on: each snapshot is
the page as it was, reduced to plain markdown with navigation, scripts, images
and links removed. No paywalled or logged-in content is collected. Fetches
respect robots.txt and wait at least 6 seconds between requests to the same
host.

Historical snapshots come from the Internet Archive's Wayback Machine
(https://web.archive.org), one capture per page per week.

If you publish a page here and want it removed, open an issue or email the
address on the maintainer's GitHub profile. It will be removed from the
current tree and from future fetches.

not affiliated with any of them.
